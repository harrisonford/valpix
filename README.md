# valpix

Open money that starts in Valparaíso. Scan to pay, show a QR to get paid,
and every account receives 1000 pesos a day.

- **Design:** [`docs/superpowers/specs/2026-11-10-valpix-design.md`](docs/superpowers/specs/2026-11-10-valpix-design.md)
- **Solana program:** [`program/`](program/README.md), live on devnet at `5AVhdmuAbx8HWJdR6h7QAPojfJHt7Z6TAa9pwj12wqcx`
- **iPhone app:** [`ios/`](ios/README.md)
- **Android app:** not started
- **Borrowing a neighbour's internet over Bluetooth:** not started

The coin, CLPC, is a closed neighbourhood currency. It is not backed by
Chilean pesos and this first version runs on Solana's test networks only.
